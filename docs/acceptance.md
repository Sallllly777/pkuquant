## 样本和结论

新增 BaoStock 输入 64,384 行、50 股票，含 2020-08 暖机至 2025-12；评价段 2021–2025 共 1,212 个日期。下载期间发生两次网络超时，随后增加逐股票缓存/有限重试，冻结的字段、样本、日期、费用和因子没有改变。数据 SHA-256 及逐股票获取时间见 [下载清单](../data/holdout_2021_2025.manifest.json)。

| 冻结候选 | 2017–2020 多空净累计收益 | 2021–2025 历史留出多空净累计收益 |
| --- | ---: | ---: |
| O03 | −31.27% | −57.14% |
| O07 | −35.41% | −61.17% |
| O10 | −53.71% | −57.42% |

历史留出只多结果也为负，等权基线约 +34.31%。本实验不支持稳定净盈利；不能回到留出段再挑选更好因子。成本是假设，不是实际券商费表；日期并集、冻结股票池、复权版本、理论借券和开盘可执行性等限制仍存在。

“方法和证据完整”与“因子有效”是不同结论；这次补全前者，并保留后者的负证据。未来样本未到，不能宣布老师的全部研究验收已经完成。已加入 CI，但本次没有上传或运行远端工作流。

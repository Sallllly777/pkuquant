# 21 个候选：代码与解释对应

定义：`L=(close-low)/(high-low)`；零振幅置缺失。`L3/L5` 为 3/5 日均值，`r` 为不填缺失的日收益；`T` 为非负换手率，`V20` 为 20 日波动（最少 10 日），`RV=V20/mean60(V20)`（最少 20 个值）。`S=1-L3`。未特别说明的 3/5 日窗口要求完整；20 日极值窗口最少 10 日。低位定义只是研究假设，不是市场事实。

| ID | 实现（横截面取高分） | 解释 / 注意 |
| --- | --- | --- |
| O01 | `-sum3((C-Low)/(High-C))` | 原型上方空间比；收盘等于高点时置缺失 |
| O02 | `-L3` | 3 日低位收盘 |
| O03 | `-L5` | 5 日低位收盘；本次冻结候选 |
| O04 | `sum3(L<0.2)` | 3 日低收盘次数 |
| O05 | `sum5(L<0.2)` | 5 日低收盘次数 |
| O06 | `-sum3(r)` | 3 日日收益和反转，不是复合收益 |
| O07 | `-sum5(r)` | 5 日日收益和反转；本次冻结候选 |
| O08 | `-sum5(min(r,0))` | 下行收益和；原式布尔处理保留 |
| O09 | `-(C/max20(C)-1)` | 距近高点跌幅 |
| O10 | `-(C/min20(C)-1)` | 越接近近低点越高；本次冻结候选 |
| O11 | `-L3 * clip(T/mean20(T),0,20)` | 旧交互，可能与高恐慌正向叙事冲突 |
| O12 | `-L3 * log1p(T)` | 使用换手率，名称中的 dollar 不代表成交金额 |
| O13 | `-L3 * RV` | **3 日**，不是旧说明中的 5 日；保留旧式 |
| O14 | `-L3 * mean5((H-Low)/C)` | 振幅 5 日窗口最少 3 日 |
| O15 | `-sum3((C-Open)/(H-Low))` | 3 日实体卖压 |
| O16 | `-L3 * max(-(Open/C.shift(1)-1),0)` | 低开交互，旧负分方向 |
| O11v2 | `S * clip(T/mean20(T),0,20)` | 低位强度乘换手冲击 |
| O12v2 | `S * log1p(T)` | 低位强度乘换手 |
| O13v2 | `S * RV` | 低位强度乘相对波动；方向修正版本 |
| O14v2 | `S * mean5((H-Low)/C)` | 低位强度乘振幅 |
| O16v2 | `S * max(-(Open/C.shift(1)-1),0)` | 低位强度乘低开幅度 |

完整 ID 与有效观测数见 [候选登记表](../runs/revised_v2/candidate_registry.json)；原式在 [factor_definitions.py](../scripts/factor_definitions.py)，v2 交互在 [research_core.py](../scripts/research_core.py)。旧布尔计数式将不可比较的缺失条件视为 False，O08 的缺失 r 在原式中进入 0；这些原式边界保留作基线，不能把它们与完全观测的信号等同。没有为取得更好结果而替换原 ID。
